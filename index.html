Synchronous FIFO Memory Controller

Verilog HDL Quartus Prime ModelSim

Designed and implemented a synchronous FIFO buffer in Verilog with an 8-bit wide, 16-deep memory array. Developed the controller logic using separate read/write pointers and status flags computed based on an internal item counter. FILO (First-In-Last-Out) Stack

Verilog HDL ModelSim

Designed an 8-bit wide, 16-deep LIFO/FILO hardware stack in Verilog. Designed stack pointer controls and counter logic to track stack depth, incorporating full and empty flag logic. Modeled and simulated simultaneous read and write (push-pop) concurrency cases to verify data routing and flag behavior.
